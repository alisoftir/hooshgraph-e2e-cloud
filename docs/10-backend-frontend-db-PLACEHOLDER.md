# فاز ۲ (به‌زودی): دیتابیس + Backend + Frontend — عمیق و موشکافانه

این فایل جای‌نگهدار است. محتوای کامل در نوبت بعدی همین سری نوشته می‌شود و مثل فاز ۱ در ادمین (`مستندات` · برچسب داخلی) و در `docs/internal/` قرار می‌گیرد.

موضوعات از پیش رزرو شده:

- مدل دامنه: User/Brand/Wallet/CloudProject/Container/Server
- MySQL پلتفرم داخل `hg-production` + بکاپ
- صف و Jobها (`ProvisionCloudProjectJob`، شارژ روزانه، تریال)
- API سطح `routes/api.php` و `routes/cloud.php`
- فرانت سایت (Nuxt panel) در برابر ادمین
- مرزهای `_prod_pull` و inventory/guard

تا آن موقع فاز ۱ (DevOps/K8s) و ماتریس Playwright را تمام کن.
