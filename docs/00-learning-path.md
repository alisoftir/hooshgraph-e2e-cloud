# مسیر یادگیری عمیق Hooshgraph (برای خودت)

این سری چهار مستند دارد. ترتیب پیشنهادی:

1. **DevOps / سرور / Kubernetes** ← همین فاز (شروع از اینجا)
2. **دیتابیس + Backend + Frontend** (فاز بعد)
3. **امنیت سرور + امنیت کد** (فاز آخر)
4. **ماتریس تست Playwright** (همزمان با فاز ۱ برای تست دستی)

## چطور بخوانی

- در ادمین: `/docs` → صفحات با برچسب «داخلی»
- روی دیسک: `projects/hooshgraph/docs/internal/`
- نسخه ZIP تست: `projects/hooshgraph/exports/`

## قانون طلایی قبل از هر تغییر

`origin/main` روی GitHub منبع حقیقت است. Hotpatch روی سرور بدون `hooshgraph_git_persist_push.py` = کار ناتمام.
